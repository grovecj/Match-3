# Art sources

Source files (e.g. `.blend`) that are *not* imported directly by Unity live here.
Unity ignores everything outside `Assets/`. Export finished sprites/models into `Assets/`.

Binary formats are tracked with Git LFS (see `.gitattributes`).

## Gems (`Gems/`)

The five token gems are generated by a Python script rather than modeled by hand, so they
can be rebuilt and tweaked reproducibly:

- `Gems/build_gems.py` builds the gem meshes, materials, lights and camera, saves
  `Gems/gems.blend`, and renders each gem to `Assets/Sprites/Gems/Gem<Name>.png`
  (256x256, transparent background).
- `Gems/gems.blend` is the generated scene: open it in Blender to look around or experiment.
  It is overwritten each time the script runs, so make lasting changes in the script.

To rebuild (from the repo root; Blender is in the Steam install on this machine):

```
blender --background --python Art/Gems/build_gems.py
```

Unity picks up the new PNGs automatically. Their import settings (Sprite, 256 Pixels Per Unit
so one gem fills one board cell) live in the `.png.meta` files and are kept across re-renders.
